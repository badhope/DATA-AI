# DATA-AI

> ようやく、御社のデータを理解してくれる AI エージェント。

ねえ、見てよ。どの会社も一緒。財務レポートの山、内部ドキュメント、顧客データ、案件ファイル、誰も触れない謎のフォルダ、あと Excel シートが数枚、これが会社の神経系みたいになってる。どれも繋がってないし、探せないし、本当に理解してる人たちは依頼に溺れてる。

**DATA-AI** は、そのために作りました。

**DATA-AI** は自社ホストできる AI エージェントで、企業のデータ——財務、社内ナレッジ、重要なやつ——のすぐ隣に住んで、くだらない仕事を代わりにやってくれます。質問すれば、ファイルを掘って、答えを根拠付きで出してくれます。タスクを任せれば、やってくれます。`/finance/2025-Q4/` の週報がほしい?2 日じゃなくて 2 分で出ます。

## 箱の中身

- **本当にあなたの業務を知ってるナレッジベース** — PDF、Word、スプレッドシート、Notion エクスポート、社内 wiki、プレーンテキスト、全部放り込めばインデックス作って学習して、10 年いる同僚みたいに答えます。
- **コードじゃなくて描くワークフロー** — ブロックをドラッグ、配線、保存。データクリーンアップ、月次レポート、「`/legal/` の新しいやつ全部まとめ」、「今四半期に期限切れる契約にフラグ」、何でもいい。
- **ちゃんと仕事を終わらせるエージェント** — 目標を投げるだけ。ステップ分解、ツール呼び出し、自己チェック、最後に報告。口出しが減って、成果物が増える。
- **モデルはあなたが選ぶ** — OpenAI、Claude、DeepSeek、ローカルの Llama、チームが贔屓にしてるマイナーなやつ。繋げば動きます。
- **ベクター DB も選ぶ** — pgvector、Milvus、Weaviate、Qdrant、Elasticsearch。すでに動いてるやつを使ってください。
- **嫌いにならない Web UI** — 管理者はコンソール、エンドユーザーはチャット、エンジニアは API。広告なし。

## なんで作ったか

SaaS を試した。「オープンコア」も試した。生 OpenAI API で自分で書くのも試した。同じボイラープレートを 4 回書いたあたりで嫌になった。

だから、本気で使いたくなるやつを作りました:

- **自社ホスト** — Linux 一台で動く、Kubernetes 不要。
- **データはあなたのもの** — 外に出さない、すべてのモデル呼び出しを監査可能。
- **営業電話なし** — オープンソース、コードはここにある。
- **「Q3 に出します」は言わない** — 誰かが必要としたら作る。

## 動かす

簡単なやつ(Docker):

```bash
git clone https://github.com/<your-org>/DATA-AI.git
cd DATA-AI/docker
cp .env.example .env
docker compose up -d
```

手動で(Docker なし):

```bash
git clone https://github.com/<your-org>/DATA-AI.git
cd DATA-AI
./dev/setup
./dev/start-api    # ターミナル 1
./dev/start-web    # ターミナル 2
```

<http://localhost:3000> を開いてください。完全なガイドは [`docs/`](./docs/) に。

## アーキテクチャ、一段落で

バックエンドは Python + Flask、ドメイン別に整理されてて見やすい。フロントエンドは Next.js(2018 年のじゃない、モダンなほう)。構造化データは PostgreSQL。埋め込みは選んだベクター DB で。バックグラウンドは Celery + Redis。プラグインでモデル・ツール・連携を追加できる、repo を fork しなくてもいい。
