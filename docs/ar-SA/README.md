# DATA-AI

> وكيل ذكاء اصطناعي يفهم بيانات شركتك أخيراً.

اسمع. أنت عارف المشكلة. كل شركة عندها كومة تقارير مالية، ووثائق داخلية، وسجلات عملاء، وملفات مشاريع، ومجلد ما حد يقدر يلمسه، وعدد شيتات إكسل هي فعلاً الجهاز العصبي للشركة. ما فيه أي شيء يتكلم مع الثاني، ما حد يلاقي أي شيء، والناس اللي فعلاً تفهم البيانات غرقى في الطلبات.

**DATA-AI** بنيناه لهذا السبب.

**DATA-AI** وكيل ذكاء اصطناعي يُستضاف ذاتياً، يعيش جنب بيانات شركتك — المالية، المعرفة الداخلية، الأشياء المهمة — ويسوي الشغل الممل عنك. اسأله سؤال، يقلب ملفاتك ويرد عليك بالمصادر. أعطه مهمة، ينفذها. تقرير أسبوعي من `/finance/2025-Q4/`؟ جاهز بدقيقتين، مو بيومين.

## وش في الصندوق

- **قواعد معرفة تعرف شغلك فعلاً** — حط فيه PDF، Word، جداول، تصديرات Notion، ويكي داخلي، نصوص خام. يفهرس، يتعلم، ويرد مثل زميل قعد في الشركة عشر سنين.
- **سير عمل ترسمها، ما تكتبها** — اسحب كم بلوك، اربطها، احفظ. تنظيف بيانات، تقارير شهرية، "لخص لي كل الجديد في `/legal/`"، "علّم العقود اللي تنتهي هالربع"، أي شي تبيه.
- **وكلاء يخلّصون الشغل** — أعطهم هدف. يكسرونه لخطوات، يستدعون الأدوات الصح، يراجعون شغلهم، ويقولون لك وش سووا. مراقبة أقل، تسليم أكثر.
- **النماذج، أنت تختار** — OpenAI، Claude، DeepSeek، Llama المحلي، ذاك الغريب اللي فريقك يحبه. ركّبه، الوكيل يستخدمه.
- **قاعدة المتجهات، أنت تختار** — pgvector، Milvus، Weaviate، Qdrant، Elasticsearch. استخدم اللي شغّال عندك.
- **واجهة ويب ما تكرهها** — كونسول للإداريين، شات للمستخدمين، API للمهندسين.

## ليش بنيناه

جرّينا خيارات SaaS. بعدها "open-core". بعدها قررنا نبنيه بأنفسنا باستدعاءات خام لـ OpenAI API، لين كتبنا نفس الـ boilerplate للمرة الرابعة وتعبنا.

فـ سوينا شي نستخدمه فعلاً:

- **استضافة ذاتية** — يشتغل على صندوق Linux واحد، بدون Kubernetes.
- **بياناتك تبقى بياناتك** — ما تطلع من شبكتك، كل استدعاء للنموذج قابل للمراجعة.
- **بدون اتصالات مبيعات** — مفتوح المصدر، الكود هنا.
- **بدون "نضيفه في Q3"** — الميزة تنبنى لما أحد يحتاجها.

## تشغيله

الطريقة السهلة (Docker):

```bash
git clone https://github.com/<your-org>/DATA-AI.git
cd DATA-AI/docker
cp .env.example .env
docker compose up -d
```

يدوي (بدون Docker):

```bash
git clone https://github.com/<your-org>/DATA-AI.git
cd DATA-AI
./dev/setup
./dev/start-api    # طرفية
./dev/start-web    # طرفية ثانية
```

افتح <http://localhost:3000>. الدليل الكامل في [`docs/`](./docs/).

## المعمار، في فقرة

الواجهة الخلفية Python + Flask، مرتبة حسب النطاقات عشان تلقى الأشياء. الواجهة الأمامية Next.js (الحديث، مو ذاك من 2018). PostgreSQL للبيانات المنظمة. قاعدة المتجهات اللي تختارها للـ embeddings. Celery + Redis لكل شي ما المفروض يوقف المستخدم. نظام إضافات تركّب نماذج وأدوات وتكاملات بدون ما تسوي fork للمستودع.
