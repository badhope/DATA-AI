# DATA-AI

> অবশেষে আপনার এন্টারপ্রাইজ ডেটা বোঝে এমন একটা AI এজেন্ট।

শুনুন। সমস্যাটা আপনি জানেনই। প্রতিটা কোম্পানিতে আছে সারি সারি ফাইন্যান্সিয়াল রিপোর্ট, ইন্টারনাল ডকুমেন্ট, কাস্টমার রেকর্ড, প্রজেক্ট ফাইল, সেই এক ফোল্ডার যেটা কেউ ছুঁতে সাহস পায় না, আর কিছু এক্সেল শিট যেগুলো আসলে কোম্পানির নার্ভাস সিস্টেম। কিছুই একটা আরেকটার সাথে কথা বলে না, কেউ কিছু খুঁজে পায় না, আর যারা ডেটা আসলে বোঝে তারা রিকোয়েস্টে ডুবে আছে।

এই জন্যই **DATA-AI** বানিয়েছি।

**DATA-AI** একটা self-hosted AI এজেন্ট — আপনার এন্টারপ্রাইজ ডেটার — ফাইন্যান্স, ইন্টারনাল নলেজ, যেটা আসলে দরকারি — পাশেই থাকে, আর আপনার বদলে একঘেয়ে কাম করে দেয়। প্রশ্ন করুন, ফাইল ঘেঁটে সোর্স সমেত উত্তর দেয়। একটা টাস্ক দিয়ে দিন, চালিয়ে দেয়। `/finance/2025-Q4/` এর সাপ্তাহিক রিপোর্ট? দুই দিন না, দুই মিনিটে।

## বাক্সে কী আছে

- **আপনার কাজ আসলে জানে এমন নলেজ বেস** — PDF, Word, স্প্রেডশিট, Notion এক্সপোর্ট, ইন্টারনাল উইকি, প্লেইন টেক্সট ডাম্প — সব ঢুকিয়ে দিন। ইনডেক্স করে, শিখে নিয়ে, দশ বছরের পুরনো কো-ওয়ার্কারের মতো উত্তর দেয়।
- **কোড না, এঁকে বানানো ওয়ার্কফ্লো** — কয়েকটা ব্লক টেনে আনুন, জুড়ে দিন, সেভ করুন। ডেটা ক্লিনআপ, মাসিক রিপোর্ট, "`/legal/` এ নতুন যা এলো সব সারমর্ম", "এই কোয়ার্টারে যেসব কন্ট্রাক্ট মেয়াদ শেষ হবে সেগুলো ফ্ল্যাগ করো" — যা ইচ্ছা।
- **কাজ শেষ করে এমন এজেন্ট** — একটা লক্ষ্য দিয়ে দিন। স্টেপে ভাগ করে, সঠিক টুল কল করে, নিজের কাজ নিজে যাচাই করে, কী করেছে জানিয়ে দেয়। কম তদারকি, বেশি ডেলিভারি।
- **মডেল, আপনি বাছুন** — OpenAI, Claude, DeepSeek, আপনার লোকাল Llama, যেই অচেনাটা নিয়ে আপনার টিম গর্ব করে — প্লাগ করুন, এজেন্ট ব্যবহার করে।
- **ভেক্টর ডিবি, আপনি বাছুন** — pgvector, Milvus, Weaviate, Qdrant, Elasticsearch। যেটা চলছে সেটাই ব্যবহার করুন।
- **বন্ধ করতে মন না-চাওয়া ওয়েব UI** — অ্যাডমিনদের জন্য কনসোল, ইউজারদের জন্য চ্যাট, ইঞ্জিনিয়ারদের জন্য API।

## কেন বানালাম

SaaS অপশন ট্রাই করলাম। তারপর "open-core"। তারপর ভাবলাম নিজেরাই বানাব, সরাসরি OpenAI API কল করে — চতুর্থবার একই বয়লারপ্লেট লিখতে লিখতে একদম বিরক্ত।

তাই বানালাম এমন কিছু যেটা আমরা নিজেরাও আসলে ব্যবহার করব:

- **Self-hosted** — একটা লিনাক্স বক্সে চলে, Kubernetes লাগে না।
- **আপনার ডেটা আপনার থাকবে** — নেটওয়ার্ক থেকে বের হয় না, প্রতিটা মডেল কল অডিট করা যায়।
- **সেলস কল নেই** — ওপেন সোর্স, কোড এখানেই।
- **"Q3 তে যোগ হবে" নেই** — কেউ দরকারি মনে করলেই ফিচার হয়।

## চালু করা

সহজ পথ (Docker):

```bash
git clone https://github.com/<your-org>/DATA-AI.git
cd DATA-AI/docker
cp .env.example .env
docker compose up -d
```

হাতে (Docker ছাড়া):

```bash
git clone https://github.com/<your-org>/DATA-AI.git
cd DATA-AI
./dev/setup
./dev/start-api    # একটা টার্মিনাল
./dev/start-web    # আরেকটা
```

তারপর <http://localhost:3000> খুলুন। পুরো গাইড [`docs/`](./docs/) এ।

## আর্কিটেকচার, এক প্যারায়

Backend Python + Flask, ডোমেইন ভাগ করে সাজানো — খুঁজতে সুবিধা। Frontend Next.js (আধুনিকটা, ২০১৮ সালেরটা না)। স্ট্রাকচার্ড ডেটার জন্য PostgreSQL। Embedding-এর জন্য আপনার পছন্দের vector DB। ইউজারকে ব্লক করা উচিত না এমন সব কিছুর জন্য Celery + Redis। প্লাগইন সিস্টেম — মডেল, টুল, ইন্টিগ্রেশন যোগ করুন, রিপো fork না করেই।
