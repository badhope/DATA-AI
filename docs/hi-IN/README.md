# DATA-AI

> आखिरकार आपके एंटरप्राइज़ डेटा को समझने वाला एक AI एजेंट।

सुनिए। आपको पता है ना। हर कंपनी के पास ढेर सारी फाइनेंशियल रिपोर्ट, इंटरनल डॉक्यूमेंट, कस्टमर रिकॉर्ड, प्रोजेक्ट फाइल, वो एक फोल्डर जिसे कोई छूने से डरता है, और कुछ एक्सेल शीट जो असल में पूरी कंपनी का नर्वस सिस्टम हैं। कुछ भी एक-दूसरे से बात नहीं करता, किसी को कुछ नहीं मिलता, और जो लोग असल में डेटा समझते हैं वो रिक्वेस्ट्स में डूबे हैं।

हमने **DATA-AI** इसीलिए बनाया।

**DATA-AI** एक self-hosted AI एजेंट है जो आपके एंटरप्राइज़ डेटा — फाइनेंस, इंटरनल नॉलेज, जो मायने रखता है — के बगल में रहता है और आपके लिए उबाऊ काम करता है। सवाल पूछिए, ये आपकी फाइलें खंगालकर सोर्स के साथ जवाब देता है। एक टास्क दे दीजिए, चला देता है। `/finance/2025-Q4/` की हफ्ते की रिपोर्ट? दो दिन नहीं, दो मिनट में हो जाती है।

## बॉक्स में क्या है

- **आपका काम असल में जानने वाले नॉलेज बेस** — PDF, Word, स्प्रेडशीट, Notion एक्सपोर्ट, इंटरनल विकी, प्लेन टेक्स्ट डंप, सब डालिए। ये इंडेक्स करता है, सीखता है, और ऐसे जवाब देता है जैसे दस साल से वहाँ कोई सीनियर है।
- **कोड नहीं, बनाकर बनाए जाने वाले वर्कफ़्लो** — कुछ ब्लॉक खींचिए, जोड़िए, सेव करिए। डेटा क्लीनअप, मंथली रिपोर्ट, "`/legal/` में जो नया है उसका सार दो", "इस तिमाही में एक्सपायर होने वाले सारे कॉन्ट्रैक्ट फ्लैग करो", जो चाहे।
- **काम खत्म करने वाले एजेंट** — एक लक्ष्य दे दीजिए। स्टेप्स में तोड़ता है, सही टूल्स कॉल करता है, अपना काम खुद चेक करता है, और बताता है क्या किया। कम देखरेख, ज़्यादा डिलीवरी।
- **मॉडल, आपकी मर्ज़ी** — OpenAI, Claude, DeepSeek, आपका लोकल Llama, वो अजीब सा जिस पर आपकी टीम कायम है। प्लग कीजिए, एजेंट इस्तेमाल करता है।
- **Vector DB, आपकी मर्ज़ी** — pgvector, Milvus, Weaviate, Qdrant, Elasticsearch। जो पहले से चल रहा है वो लगा लीजिए।
- **बंद करने का मन न करने वाला वेब UI** — एडमिन के लिए कंसोल, एंड-यूज़र के लिए चैट, इंजीनियर के लिए API।

## क्यों बनाया

SaaS ऑप्शन आज़माए। फिर "ओपन-कोर"। फिर सोचा खुद बनाएँगे, सीधे OpenAI API कॉल करके, जब चौथी बार वही बॉयलरप्लेट लिखते-लिखते तंग आ गए।

तो कुछ ऐसा बनाया जो हम खुद असल में इस्तेमाल करें:

- **Self-hosted** — एक Linux बॉक्स पर चलता है, Kubernetes की ज़रूरत नहीं।
- **डेटा आपका है** — नेटवर्क से बाहर नहीं जाता, हर मॉडल कॉल ऑडिटेबल है।
- **सेल्स कॉल नहीं** — ओपन सोर्स, कोड यहीं है।
- **"Q3 में जोड़ देंगे" नहीं** — जिसे ज़रूरत है वो बन जाता है।

## चालू कैसे करें

आसान तरीका (Docker):

```bash
git clone https://github.com/<your-org>/DATA-AI.git
cd DATA-AI/docker
cp .env.example .env
docker compose up -d
```

हाथ से (बिना Docker):

```bash
git clone https://github.com/<your-org>/DATA-AI.git
cd DATA-AI
./dev/setup
./dev/start-api    # एक टर्मिनल
./dev/start-web    # दूसरा
```

<http://localhost:3000> खोलिए। पूरी गाइड [`docs/`](./docs/) में है।

## आर्किटेक्चर, एक पैराग्राफ में

Backend Python + Flask, डोमेन के हिसाब से सजाया हुआ ताकि चीज़ें मिल जाएँ। Frontend Next.js (आधुनिक वाला, 2018 वाला नहीं)। स्ट्रक्चर्ड डेटा के लिए PostgreSQL। Embeddings के लिए आपकी पसंद का vector DB। जो यूज़र को ब्लॉक न करे उसके लिए Celery + Redis। प्लगिन सिस्टम ताकि आप मॉडल, टूल और इंटीग्रेशन जोड़ सकें, रेपो fork किए बिना।
