# DATA-AI

> 드디어 우리 회사 데이터를 이해하는 AI 에이전트.

있잖아, 다들 알잖아. 모든 회사엔 재무 보고서 산더미, 내부 문서, 고객 기록, 프로젝트 파일, 아무도 못 건드리는 그 폴더, 회사의 신경망인 엑셀 시트 몇 장이 있어. 서로 말이 안 통하고, 아무도 못 찾고, 진짜 아는 사람들은 요청에 파묻혀 있고.

**DATA-AI** 그거 때문에 만들었어요.

**DATA-AI** 는 자가 호스팅 가능한 AI 에이전트예요. 회사 데이터 — 재무, 내부 지식, 진짜 중요한 것 — 옆에 딱 붙어서, 지루한 일을 대신 해줘요. 질문하면 파일 뒤져서 출처랑 같이 답해주고, 일 시키면 돌려요. `/finance/2025-Q4/` 주간 보고서? 이틀이 아니라 2 분이에요.

## 박스 안에 뭐가 있냐면

- **우리 회사 일을 아는 지식 베이스** — PDF, Word, 스프레드시트, Notion 내보내기, 내부 위키, 텍스트 덤프 다 때려넣으면 인덱싱하고 학습해서 10 년 된 동료처럼 답해줘요.
- **코드 말고 그림으로 그리는 워크플로우** — 블록 끌어다 놓고 선 연결하고 저장. 데이터 정리, 월간 보고서, "`/legal/` 에 새로 생긴 거 다 요약", "이번 분기 만료 계약 플래그", 다 돼요.
- **일을 끝까지 하는 에이전트** — 목표만 던져줘. 단계 쪼개고, 도구 부르고, 자가 점검하고, 뭐 했는지 보고. 잔소리 줄고, 산출물 늘어남.
- **모델은 맘대로** — OpenAI, Claude, DeepSeek, 로컬 Llama, 팀에서 좋아하는 좀 알려지지 않은 거. 꽂으면 돌아가요.
- **벡터 DB 도 맘대로** — pgvector, Milvus, Weaviate, Qdrant, Elasticsearch. 이미 도는 거 쓰면 됨.
- **짜증 안 나는 Web UI** — 관리자용 콘솔, 일반 사용자용 채팅, 엔지니어용 API. 광고 없음.

## 왜 만들었냐면

SaaS 써봤고, "오픈 코어"도 써봤고, 그냥 OpenAI API 로 직접 짜는 것도 해봤는데, 같은 보일러플레이트를 네 번째 쓰는 순간 질렸어요.

그래서 진짜 우리가 쓸 만한 걸 만들었어요:

- **자가 호스팅** — 리눅스 박스 하나로 돌아가요, 쿠버네티스 필요 없음.
- **데이터는 당신 거** — 밖으로 안 나가고, 모든 모델 호출 감사 가능.
- **영업 전화 없음** — 오픈 소스, 코드 여기 있어요.
- **"Q3 에 출시합니다" 안 함** — 누가 필요로 하면 만들어요.

## 돌리는 법

제일 쉬운 거(Docker):

```bash
git clone https://github.com/<your-org>/DATA-AI.git
cd DATA-AI/docker
cp .env.example .env
docker compose up -d
```

수동(Docker 없이):

```bash
git clone https://github.com/<your-org>/DATA-AI.git
cd DATA-AI
./dev/setup
./dev/start-api    # 터미널 하나
./dev/start-web    # 다른 하나
```

<http://localhost:3000> 여세요. 전체 가이드는 [`docs/`](./docs/) 에.

## 아키텍처, 한 단락

백엔드는 Python + Flask, 도메인별로 정리돼서 찾기 쉬움. 프론트는 Next.js(2018 년식 말고 최신). 정형 데이터는 PostgreSQL, 임베딩은 골라서. 백그라운드는 Celery + Redis. 플러그인으로 모델, 툴, 연동 추가 가능, repo fork 안 해도 됨.
